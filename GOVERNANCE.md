# Governance

English | [简体中文](GOVERNANCE.zh-CN.md)

## Roles

- Maintainers merge ABAR changes and publish releases.
- Committers review and prepare changes.
- Contributors submit issues and pull requests.

## Decision process

1. Open a design issue for `abar-api`, Artifact, Skill, or runtime semantic
   changes.
2. Resolve compatibility and security questions in review.
3. Require maintainer approval for ABAR changes.
4. Record irreversible decisions as ADRs under `docs/adr/`.

Technical decision records and release notes describe accepted implementation
work. They do not establish compatibility guarantees beyond the published
versioned contracts.
